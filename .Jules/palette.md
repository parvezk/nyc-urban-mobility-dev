## 2024-08-05 - Monochromatic Focus Rings against Dark Thematic Backgrounds
**Learning:** Default browser focus rings or generic tailwind rings (like `ring-blue-500`) often clash with monochromatic UI requirements or lack sufficient contrast against very dark thematic backgrounds (`bg-slate-900` or `bg-slate-800`), making keyboard navigation confusing or invisible for users relying on it.
**Action:** When implementing keyboard accessibility in monochromatic dark UIs, explicitly define the focus ring color with a light slate, and crucially, use ring offsets with the background color (`focus-visible:ring-slate-400 focus-visible:ring-offset-2 focus-visible:ring-offset-slate-900`) to guarantee a visible, high-contrast, double-border effect that doesn't break the design system.
